## Notater

### Spm 5 — First-best skjer aldri i praksis?
- **Spm:** Man vil ha first-best men det skjer sjelden i praksis?
- **Forklaring:** Riktig. Alltid second-best fordi du aldri ser innsats direkte, output har støy, kontrakter er ufullstendige. Alt i faget = verktøy for å krympe gapet mot first-best.
- **Husk:** Second-best = virkeligheten alltid. Faget handler om å minimere gapet.

### Spm 4 — Hvorfor CC fjerner informasjonsproblemet → first-best
- **Spm:** Forklar mer: «First-best = null bortkastet, CC fjerner informasjonsproblemet»
- **Forklaring:** Uten CC: sjefen ser ikke innsats → må gi høy bonus (β) → agent bærer risiko → risikopremie = sløsing. Under CC: sjefen ser innsats direkte → lav β, høy fast lønn, innsats kontraktfestet → null risikopremie, null shirking = first-best.
- **Husk:** Informasjonsproblem tvinger frem risiko hos agent → risikopremie er det «bortkastede». CC eliminerer selve informasjonsproblemet → ingen risikopremie nødvendig.

### Spm 3 — Hva betyr «kontrakteres bort til first-best»?
- **Spm:** Hva menes med at konfliktene kan kontraktes bort med first-best?
- **Forklaring:** Under CC kan sjefen observere + bevise innsats → skriver direkte inn i kontrakt hva som skal gjøres → ingen grunn til å avvike → 0 tap. First-best = resultatet uten noen form for sløsing.
- **Husk:** First-best = null tap. CC gjør det mulig fordi informasjonsproblemet forsvinner. I virkeligheten ser sjefen bare output (som inneholder støy) → kan ikke bevise slacking → Q04.

### Spm 2 — Forholdet mellom Q03 og costless contracting
- **Spm:** Q03 handler om ting som skjer mot costless contracting?
- **Hvor:** `questions/q03.tex` l. 9, 19–20, 85–86
- **Forklaring:** Q03 presenterer 5 konflikter + viser at CC *løser* dem (benchmark). Q04 er der CC brytes. Q03+Q04 er et par: Q03 setter opp idealverden, Q04 river den ned.
- **Husk:** Q03 = konflikter + CC som løsning. Q04 = hva skjer når CC ikke holder. Ikke bland inn moral hazard i Q03.

### Spm 1 — Costless contracting
- **Spm:** Forklar meg costless contracting
- **Hvor:** `theories/costless-contracting.tex` l. 4–18
- **Forklaring:** Tenkt idealtilstand der kontrakter er gratis, fullstendige og verifiserbare → first-best uten agency costs. Brukes som benchmark, ikke som virkelighet.
- **Husk:** (1) Det er en benchmark, ikke virkelighet. (2) Under CC = first-best, ingen tap. (3) Når CC brytes → costly contracting (Q04) → moral hazard + adverse selection.
