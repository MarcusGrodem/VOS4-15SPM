## Q01–Q05 teorier

- responsibility-centers — De 5 centertyper (cost, expense, revenue, profit, investment) og når hver bør velges — Brukt i: Q01, Q02, Q05
- controllability-principle — Prinsippet om at ledere kun skal evalueres på det de kan kontrollere — Brukt i: Q01, Q05, Q10
- transfer-pricing — Interne afregningspriser; metoder (market/MC/full cost/cost-plus/negotiated) under costless og asymmetrisk informasjon — Brukt i: Q02, Q05
- principal-agent — Principal-agent-rammeverket; hidden action vs hidden information; first-best vs second-best — Brukt i: Q02, Q03, Q04, Q08
- incentive-conflicts-owner-manager — De 5 klassiske konfliktene (shirking, perks, risk aversion, time horizon, overinvestment) — Brukt i: Q03, Q04
- costless-contracting — Benchmark: komplette, kostnadsfrie og verifiserbare kontrakter → first-best — Brukt i: Q03, Q04
- costly-contracting — Søk-, forhandlings- og håndhevingskostnader; ufullstendige kontrakter; second-best — Brukt i: Q04, Q05
- game-theory — Dominante strategier, Nash, sekvensielle og repeterte spill; anvendelse på principal-agent — Brukt i: Q03
- moral-hazard — Post-kontraktuelt skjult handling; monitoring, bonding, residual loss — Brukt i: Q04, Q09
- adverse-selection — Pre-kontraktuelt skjult informasjon; lemons, signaling, screening — Brukt i: Q04
- organizational-architecture — Den tre-benede skammelen: S1 beslutningsrett + S2 måling + S3 belønning; complementarity — Brukt i: Q05
- agency-costs — Monitoring + bonding + residual loss (Jensen–Meckling) — Brukt i: Q04, Q05, Q06, Q09, Q10
- specific-vs-general-knowledge — Hayek/Jensen-Meckling: hvorfor spesifik viden krever desentralisering — Brukt i: Q02, Q05, Q06, Q07

## Q07 teorier

- decision-management-control — Fama & Jensen: initiation + implementation (management) vs ratification + monitoring (control); separasjon når beslutningstaker ≠ residual claimant — Brukt i: Q02, Q07, Q10
- externalities — Handlinger med konsekvenser for tredjepart som ikke prises; internalisering via Coase/Pigou/intern prising — Brukt i: Q07
- residual-claimants — Parten med rett på residual cash flow; Jensen & Meckling eierskap → insentiv til verdimaksimering — Brukt i: Q07
- decision-rights-allocation — Prosessen for å plassere beslutningsrett der videnen er, balansert mot agentkostnader og koordinasjon — Brukt i: Q07

## Q09 teorier

- optimal-effort-model — Agentens FOC (β·α=c'(e*)) + prinsipalens β*-valg (risk-incentive trade-off); to grafiske modeller — Brukt i: Q09
- incentive-coefficient — β i W=W₀+βQ; determinanter: kontrollerbarhet, støy, risikoaversjon, produktivitet — Brukt i: Q09, Q10
- risk-sharing — Fordeling av eksogen utfallsrisiko; risikonøytral prinsipal vs risikoavers agent; incentive–risk trade-off — Brukt i: Q09
- fixed-vs-variable-pay — Dekomponering W₀+βQ: W₀ dekker reservation utility (vrir ikke innsats), βQ vrir innsats (bringer risiko) — Brukt i: Q09

## Q10 teorier

- ratchet-effect — Fremtidige mål basert på historisk prestasjon → ansatte holder igjen (sandbagging); sovietopprinnelse — Brukt i: Q10
- gaming-in-performance-measurement — Manipulasjon av målet i stedet for verdiskaping; horisontproblem; Goodhart's law — Brukt i: Q10
- absolute-vs-relative-performance — Absolutt (uavhengig) vs relativ (vs peers); relativ filtrerer felles sjokk (informativeness) — Brukt i: Q10
- subjective-vs-objective-performance — Objektiv (forhåndsdefinert, verifiserbar) vs subjektiv (holistisk ex-post); hybridløsning — Brukt i: Q10
